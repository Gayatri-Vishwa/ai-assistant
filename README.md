# 🤖 AI Voice Assistant - Backend

A powerful backend for the **AI Voice Assistant** built with **Node.js**, **Express.js**, and the **Google Gemini API**. It processes user queries, generates AI-powered responses, and serves them securely through REST APIs.

---

## 🚀 Features

* 🤖 AI-Powered Responses using Google Gemini
* 🔐 Secure REST API
* ⚡ Fast Response Generation
* 🌐 Express.js Server
* 📡 JSON API Endpoints
* 🔄 CORS Enabled
* ⚙️ Environment Variable Configuration
* ☁️ Render Deployment Ready

---

## 🛠️ Tech Stack

* Node.js
* Express.js
* Google Gemini API
* Axios
* dotenv
* CORS

---

## 📦 Installation

```bash
git clone https://github.com/Gayatri-Vishwa/AI-Virtual-Assistant-Backend.git
cd AI-Virtual-Assistant-Backend
npm install
npm start
```

> If your project uses **nodemon**, run:

```bash
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file in the project root and add:

```env
PORT=8000

GEMINI_API_KEY=your_gemini_api_key

CLIENT_URL=https://ai-assistant-frontend-ashen.vercel.app
```
